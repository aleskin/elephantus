# Elephantus

Сборник коротких смешных мини-игр в духе WarioWare для 1–4 игроков. Придумывает игру Полина
(8 лет), код пишет ИИ-агент, папа Саша помогает.

Первая мини-игра — **цирковой слоник**: на двух ногах дойти до обруча и перепрыгнуть его с
сальтухой. Как играть и какие кнопки — в [GAMES.md](GAMES.md).

Версия: см. `Makefile.version`, история — `CHANGELOG.md`.

## Сборка (Ubuntu)

Нужно: компилятор C++20 (g++ 13+), CMake 3.20+, git, заголовки X11/OpenGL/Wayland для raylib.

```bash
sudo apt install build-essential cmake git \
    libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev \
    libgl1-mesa-dev libwayland-dev libxkbcommon-dev
```

raylib 6.2 скачивается и собирается сам при первой сборке (нужен интернет). GoogleTest берётся
из `/usr/src/googletest`, если его нет — тоже скачивается.

```bash
make build    # собрать в build/
make run      # собрать и запустить игру
make test     # тесты ядра
make shots    # прогнать сценарии и сохранить снимки в build/shots/<мини-игра>/ и экраны меню в build/shots/screens/
```

Звук — через звуковую систему по умолчанию (PulseAudio/PipeWire); нет звукового устройства —
игра идёт без звука. Сценарии и снимки (`--script`, `--screens`) звук не включают.

Надписи — шрифтом `assets/fonts/Nunito-ExtraBold.ttf` (лицензия SIL OFL 1.1, текст — в
`assets/fonts/OFL.txt`); без него игра не запускается.

Игра ищет папку `assets/` рядом с собой; запускать из корня репозитория или указать
`--assets DIR`.

## Параметры запуска

```bash
./build/circus_elephant [--assets DIR] [--minigame ID --script FILE [--shots DIR]] [--screens DIR]
```

- Без параметров — заставка, меню, выбор мини-игры.
- **`--script FILE`** — сыграть сценарий нажатий в скрытом окне и сохранить снимки в `--shots DIR`;
  **`--minigame ID`** — в какой мини-игре (по умолчанию `circus`).
- **`--screens DIR`** — сохранить снимок каждого экрана меню в `DIR` и выйти.

## Конфиг игры

`assets/config.txt` — числа игры (скорость слоника, высота прыжка, «очень быстро» между кнопками)
и раскладка джойстика. Меняешь, сохраняешь — игра подхватывает сама примерно через секунду.
Ошибка в файле показывается красной строкой внизу экрана, игра продолжает со старыми числами.
